# ✦ Escriba — para escritores

Escriba é um editor **100% offline, rápido e sem distrações** feito para quem vive escrevendo. Nada de login, nuvem ou assinaturas. Só você e suas histórias.

Abra o `index.html` e comece a escrever.

![screenshot](screenshot.png)

## Por que o Escriba?

Apps como Word e Google Docs são para escritório. O Escriba foi pensado para **ficção, roteiro e diário de escrita** — com ferramentas que escritores de verdade usam.

## Funcionalidades

### ✍️ Editor profissional
- Formatação rica (negrito, itálico, títulos, listas)
- Modo Roteiro Hollywood (CENA, AÇÃO, PERSONAGEM, DIÁLOGO)
- Contador ao vivo de palavras, caracteres e tempo de leitura
- Auto-save a cada 800ms

### 🎯 Foco de verdade
- **Modo Foco:** esconde tudo, só o texto
- **Modo Máquina de Escrever:** mantém a linha sempre no centro
- Tema escuro, claro e sépia

### 📊 Produtividade
- Dashboard com total de palavras e histórias
- Meta diária com barra de progresso
- **Pomodoro integrado** (🍅 25min)
- Histórico de versões automático (últimas 20)

### 🗂️ Organização
- Notas rápidas com cores, fixar e contador
- Modelos prontos: Conto, Romance, Roteiro, Diário
- Busca instantânea
- Exportar em TXT, MD, HTML ou PDF

### 🔒 Privacidade total
- Tudo salvo no seu navegador (localStorage)
- Backup e restauração em JSON com 1 clique

## Como usar
1. Baixe o ZIP
2. Abra `index.html` no Chrome/Edge/Firefox
3. Pronto.

> Dica: instale como PWA para usar como app nativo.

## Stack
HTML, CSS e JavaScript puro. Zero dependências.
